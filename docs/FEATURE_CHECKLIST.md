# Feature Checklist: Typing Master

This document tracks the status of all requested features from the specification.

## 1. Core Typing Experience
- [ ] Real-time WPM calculation
- [ ] Real-time accuracy calculation
- [ ] Smooth caret movement
- [ ] Error highlighting (incorrect, extra characters)
- [ ] Time-based tests (15s, 30s, 60s, 120s)
- [ ] Word-count tests (10, 25, 50, 100 words)
- [ ] Custom text mode
- [ ] Live charts during typing (optional setting)
- [ ] Multi-language support (word lists)
- [ ] Blind mode (hide typing feedback)
- [ ] Confidence mode (prevent backspace)

## 2. Curriculum / Lessons
- [ ] Lesson progression system
- [ ] Individual letter focus lessons
- [ ] N-gram and bigram practice
- [ ] Symbol and number lessons
- [ ] 3-star rating system per lesson
- [ ] Lock/Unlock progression logic

## 3. Mini-Games
- [ ] Game Engine Registry
- [ ] Game 1: Word Drop (falling words)
- [ ] Game 2: Typing Invaders or similar
- [ ] Game high-score tracking

## 4. Statistics & Analytics
- [ ] Recent session history view
- [ ] Lifetime statistics (total time, tests, avg WPM/Accuracy)
- [ ] Interactive charts for session progress
- [ ] Calendar heatmap for daily activity
- [ ] Badges / Achievements system

## 5. Customization & Settings
- [ ] Theme switcher (10+ themes)
- [ ] Font size configuration
- [ ] Font family selection
- [ ] Caret style configuration (block, line, underline)
- [ ] Sound effects toggle and volume
- [ ] Export/Import settings

## 6. Architecture & Tech
- [ ] React + TypeScript + Vite setup
- [ ] Redux Toolkit state management
- [ ] IndexedDB (Dexie.js) storage implementation
- [ ] PWA setup (Manifest, Service Worker)
- [ ] Offline support testing

## 7. UI/UX
- [ ] Responsive design for desktop and tablet
- [ ] Keyboard navigation support
- [ ] Framer Motion animations
- [ ] Accessibility (a11y) considerations
